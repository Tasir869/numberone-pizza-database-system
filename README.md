# Numberone Pizza Database System

## Overview

This project presents the design and implementation of a relational database
for a fictional pizza restaurant.

The database supports customer orders, menu items, ingredients, suppliers,
inventory management, employees, shifts, deliveries and staff payments.

This project was originally completed as an individual university database
design project and has been reorganised as a professional portfolio project.

## Project Scope

The database was designed to support:

- Customer records and order history
- Phone and walk-in orders
- Pickup and delivery orders
- Menu items and ingredient requirements
- Ingredient stock levels and stocktake records
- Supplier and ingredient orders
- Employee and driver records
- Staff shifts and payroll information

## Skills Demonstrated
